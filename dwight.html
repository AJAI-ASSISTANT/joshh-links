Your email signature

Pick a colour scheme, press Copy signature, then paste it into your email settings (steps below). About a minute.

Gmail (computer)
  1. Gmail → ⚙ Settings → See all settings → General tab.
  2. Under Signature → Create new → name it "Vibration Lighting" → click in the box → paste (Cmd + V on Mac, Ctrl + V on Windows).
  3. Under Signature defaults, pick it for new emails and on reply/forward.
  4. Scroll to the bottom → Save Changes. Your Gmail phone app uses it too once set here.
Outlook
  1. Outlook on the web / new Outlook: ⚙ Settings → Account → Signatures → + New signature → paste → choose it as the default for new messages and replies → Save.
  2. Classic Outlook (Windows): File → Options → Mail → Signatures… → New → paste → set defaults → OK.
Apple Mail (Mac)
  1. Mail → Settings → Signatures → choose the account → +.
  2. Untick Always match my default message font, then paste into the right-hand box.
iPhone Mail app
  1. Open this page on the iPhone, press Copy signature.
  2. Settings → Apps → Mail → Signature → paste. (If the logo does not paste there, the text still does; the iPhone Mail app is limited.)

If copying is blocked in your browser, select everything in the white box with your mouse and copy it the usual way.
